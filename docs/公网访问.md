## 运行操作

在 `D:\智慧` 下使用 Git Bash 脚本：

```bash
./scripts/start-public-sites.sh
./scripts/status-public-sites.sh
./scripts/stop-public-sites.sh
```

智慧图书馆发布构建使用：

```bash
./scripts/build-public.sh
```

日志统一保存在 `D:\智慧\logs`，运行时 PID 和临时 SSH 密钥保存在被 Git 忽略的 `D:\智慧\.runtime\public-sites`。
